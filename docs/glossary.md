# Glossary

Plain-language definitions of the supply-chain terms used in this project,
aligned with ASCM/APICS (CSCP) usage.

| Term | Definition |
|---|---|
| **ABC classification** | Ranking items by annual consumption value to focus control on the few items that drive most of the value |
| **ADI (average demand interval)** | Average number of periods between non-zero demands; > 1.32 indicates intermittent demand |
| **Allocated inventory** | Stock committed to customer orders but not yet shipped |
| **Carrying (holding) cost** | Annual cost of holding inventory — capital, storage, insurance, obsolescence — as % of value |
| **Coefficient of variation (CV)** | Standard deviation ÷ mean; relative variability |
| **Cycle service level (CSL)** | Probability of no stockout during a replenishment cycle |
| **Days of supply (DOS)** | How many days current stock lasts at forecast demand |
| **Dead stock** | Inventory with no demand for an extended period, at risk of write-off |
| **DIO (days inventory outstanding)** | 365 ÷ inventory turns; average days inventory is held |
| **EOQ (economic order quantity)** | Lot size that minimises the sum of ordering and holding cost |
| **Excess inventory** | Stock above what policy requires to meet projected demand and safety stock |
| **Fill rate** | Share of demand (units) shipped from stock |
| **Forecast bias** | Persistent over- or under-forecasting |
| **FVA (forecast value added)** | Improvement of a forecast over a naive baseline |
| **GMROI** | Gross margin return on inventory investment |
| **Inventory position** | On hand + on order − allocated; the supply available to cover future demand |
| **Inventory turns** | Annual cost of goods sold ÷ average inventory |
| **Lead time** | Time from placing a purchase order to receiving the goods |
| **Lead-time demand** | Demand expected while waiting for an order to arrive |
| **MOQ (minimum order quantity)** | Smallest quantity a supplier accepts per order |
| **Order multiple** | Quantity increment an order must be rounded to (case, pallet) |
| **OTIF (on time, in full)** | Share of order lines delivered complete by the promised date |
| **Periodic review** | Inventory is reviewed at fixed intervals (here monthly) rather than continuously |
| **PPV (purchase price variance)** | Difference between actual purchase price and standard cost × quantity |
| **Protection interval** | Lead time + review period — the time stock must cover in a periodic-review system |
| **Reorder point (s)** | Inventory position at or below which an order is placed |
| **Safety stock** | Buffer held to protect against demand and supply uncertainty |
| **S&OP** | Sales and operations planning — monthly process aligning demand, supply and financial plans |
| **Tracking signal** | Cumulative forecast error ÷ MAD; detects persistent bias |
| **WAPE** | Weighted absolute percentage error: Σ|actual − forecast| ÷ Σ actual |
| **XYZ classification** | Grouping items by demand variability (forecastability) |
