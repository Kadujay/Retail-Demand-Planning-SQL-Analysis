# Data

All data in this project is **synthetic**, generated by
`src/data_generation.py` with a fixed random seed (see `DataGenerationConfig`
in `src/config.py`). No employer, customer or proprietary data is used.

| Folder | Contents | In Git? |
|---|---|---|
| `raw/` | Generated source tables (products, suppliers, demand, inventory, POs, deliveries) | No — regenerate with the pipeline |
| `processed/` | Validated / enriched tables used by the analytics modules | No — regenerate with the pipeline |

Raw and processed data are git-ignored because they are fully reproducible
from the seed. The curated result files in `outputs/` are committed so the
results are visible without running anything.

Demand and supplier archetypes and the correlations built into the data are
documented in Phase 2.

## Why orders *and* shipments

Demand is captured as customer order quantity, with shipments stored
separately. Forecasting on shipments would bake past stockouts into future
forecasts (censored demand), and the ratio shipped / ordered gives a measured
fill rate. See `docs/methodology.md` §1.
